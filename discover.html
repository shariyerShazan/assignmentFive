Question-3: What is event bubbling in the DOM?

Event bubbling is a mechanism in the DOM where an event starts from the target element and then propagates up to its parent elements.

Question-4: How do you create, add, and remove elements using JavaScript?

To create elements: document.createElement('tagName').
To add elements: appendChild(), append(), prepend(), or insertBefore().
To remove elements: removeChild() or remove().
